# Periphery OSS Actions fixture

This public SwiftPM repository is a manual smoke-test fixture for the
[`periphery-pro/actions`](https://github.com/periphery-pro/actions) reusable
workflow.

Run **Test OSS scan workflow** from the Actions tab after a stable `@v1`
workflow release is available. The workflow deliberately uses the moving `@v1`
tag and has no automatic trigger.
